# FreeScout AI Integration Module (Official)

Full documentation: https://freescout.net/module/ai-integration/

**Supported AI Providers**: *OpenAI, Gemini (Google AI Studio), Anthropic (Claude), DeepSeek, xAI, Mistral AI, Groq, Perplexity, Together AI, Fireworks AI, DigitalOcean Serverless Inference, Z.AI, Ollama (Local), LM Studio (Local), OpenRouter, Custom (OpenAI-compatible)*.

Google's Gemini offers [API keys](https://aistudio.google.com/api-keys) with relatively generous free tiers.

## Features
* Drafting replies with AI
* Summarizing conversations
* Improving replies with AI (checking spelling, grammar, etc)
